# 3D Game

This is a 3D Shooter Game built on the Bevy engine built in Rust.

All assets for the source code will be linked, but they will be included in the .zip in the assets folder.
You can try your luck by replacing the textures in the assets but they are not guaranteed to work.

Links:
Rocky Terrain Texture: https://polyhaven.com/a/rocky_terrain
Cliff Side Texture: https://polyhaven.com/a/cliff_side
Asphalt Snow Texture: https://polyhaven.com/a/asphalt_snow
